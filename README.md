# 星星骰娘-重骰版！

为 Astrbot 设计的 TRPG 骰子插件（参考 [Dice!](https://forum.kokona.tech/) 与 [海豹](https://dice.weizaima.com/) 的实现），提供掷骰、技能判定、人物卡管理与日志导出等常用功能，便于在群聊中进行跑团玩法支持。

为所有使用astrbot平台但想要有与其他骰娘相同体验的骰主设计。

基于[TRPGdice-Complete](https://github.com/WhiteEurya/Astrbot_plugin_TRPGdice-Complete)二次开发，提供配置文件以管理骰娘输出风格。

---

## 平台支持

本插件通过**平台适配器**抽象层支持多种 AstrBot 后端：

| 平台 | 状态 | 特点 |
|------|------|------|
| **OneBot / QQ** (aiocqhttp) | ✅ 稳定 | 完整功能：回复+@、群昵称同步、撤回事件 |
| **Telegram** | 🧪 实验性 | 文本回复、群成员名称获取 |
| **QQ 官方机器人** | 🧪 实验性 | 群消息回复、C2C 私聊 |
| **其他平台** | ⚠️ 未适配 | 回退纯文本回复，部分功能不可用 |

对没有专用适配器的平台，插件会自动降级为纯文本回复，核心功能不受影响。

## 安装

**推荐**：使用Astrbot插件市场安装

或：

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/HosisoraLing/astrbot_plugin_trpgdice_rerolled.git
   ```

2. 将插件文件/目录放入 Astrbot 的插件目录。

3. 启动或重启 Astrbot，确认控制台输出已加载本插件。

## 功能

- **基础掷骰**
  - 支持常见的 DnD / CoC / 跑团检定
  - 群聊与私聊均可使用（私聊结果直接回复给发送者，`.rh` 不再额外提示）
  - 支持算式，例如 `1d100+5`、`3d6+2d4-1d8`
  - 支持保留最高骰，例如 `10d6k5`（掷10个d6保留最高5个）
  - 支持连续掷骰，例如 `6#4d6k3`（掷4d6k3六次）

- **角色卡与检定**
  - 支持角色属性绑定与管理
  - 支持 **技能检定** (普通/奖励骰/惩罚骰)
  - 支持 **理智检定** (SAN Check) 与疯狂症状生成
  - 支持 **技能成长** 判定

- **先攻系统**
  - 先攻掷骰与排序
  - 回合推进管理

- **日志与记录**
  - 自动保存跑团对话日志
  - 支持导出 JSON 格式记录，兼容主流染色器
  - 支持暂停/恢复/删除日志会话
  - 支持日志统计（`.log stat`）——消息数、掷骰数、参与人数、时长
  - **`.log off` 自动阶段总结**：暂停时用 LLM 概括本段剧情，并提取 2~5 条高光片段
    - 默认使用当前对话模型，也可在 `log_summary.provider_id` / `log_summary.model` 单独指定
    - 只总结上次总结后的新消息，反复 on/off 不会重复概括
    - 结果保存在会话的 `summaries` / `highlights` 字段，供后续绘图插件读取
  - **`.log draw` 高光配图**：手动把最近一段总结中的高光交给[万象画卷](https://github.com/diaomin66/astrbot_plugin_omnidraw)画成插图
    - 默认手动触发，不会在 `.log off` 时自动生图（避免意外消耗额度）
    - 支持 `.log draw`（第 1 条）、`.log draw 2`（第 2 条）、`.log draw all`（前几张）、`.log draw cover`（用整段小结画章节封面）
    - 画风基准需在配置中手动填写；已生成的插图保存在 `data/highlight_images/`，重复执行默认复用
    - 后台插件页「联动检查」可一键确认万象画卷是否安装、启用并配置好画图节点

- **错误提示**
  - 参数不完整或格式错误时，自动给出正确的用法提示
  - 包含 `.ra`、`.en`、`.st`、`.pc`、`.log`、`.fireball` 等命令的校验

- **LLM 美化模式**
  - 默认 `decorate`：把玩家名、骰点、判定结果固定为 `core`，LLM 只写 `core` 前后的 prefix/suffix，数值与判定不会被改写
  - 可切换 `rewrite`：LLM 重写整句话，兼容旧行为
  - 可单独指定更便宜的 Provider / 模型（`llm_mode.provider_id` / `llm_mode.model`），留空则使用当前会话模型
  - 支持自定义提示词；系统会自动追加 `{"prefix":"...","suffix":"..."}` 的 JSON 输出协议
  - LLM 不可用或返回格式不合法时自动回退为 `core`，不影响正常使用

- **LLM 工具函数（Function Calling）**
  - 注册为 Astrbot Function Calling 工具，LLM 可以主动调用掷骰、技能检定等功能
  - 在对话中说"帮我掷1d100"，LLM 会自动调用工具并返回结果
  - LLM 可通过对话直接修改输出模板、开关美化模式

- **按群独立的骰娘开关**
  - `.bot` 输出一段可自定义的骰娘简介（本群状态、平台、运行时长、当前人物卡、玩法速览）
  - `.bot off` 关闭**本群**的骰娘功能：掷骰、人物卡、日志、先攻、LLM 工具
  - `.bot on` 重新开启本群；开关按群号持久保存，重启后依然有效
  - 群内所有成员都可以开关，无需管理员；其他群聊、其他插件与 LLM 对话不受影响

- **`.dismiss` 退群**
  - 任何人（群内任意成员）发送 `.dismiss`，骰娘会先留一句告别语，然后立即退出该群
  - 支持 OneBot/QQ（`set_group_leave`）与 Telegram（`leave_chat`）；其他平台会提示手动移除
  - 不受 `.bot off` 影响：本群功能已关闭时依然可以退群

- **自定义风格回复**
  - 所有输出文本均可在 Astrbot 插件配置中自由修改
  - 每个掷骰语句、判定结果、系统提示都支持个性化定制
  - 配置项说明中标注了可用的变量占位符
  - 也可通过对话让 LLM 帮你写模板并自动保存应用

## 快速使用示例

> 插件加载后，可在群聊中使用下列示例指令进行测试（支持 `.` `。` `/` 作为前缀）

* 基本掷骰：
  ```
  .r 1d100          # 掷1个100面骰
  .r 3d6+5          # 掷3个6面骰+5
  .r 10d6k5         # 掷10个d6，保留最高5个
  .r 6#4d6k3        # 掷4d6k3六次（连续掷骰）
  .r 3#2d20+5       # 掷2d20+5三次
  ```

* 技能判定：
  ```
  .ra 侦查 50       # 进行侦查检定（技能值50）
  .rab 2 射击       # 带2个奖励骰的射击检定
  .rap 1 闪避       # 带1个惩罚骰的闪避检定
  ```

* 人物卡管理：
  ```
  .pc create <名字>   # 创建人物卡
  .pc show             # 显示当前人物卡
  .pc change <名字>    # 切换人物卡
  .st san-5            # 修改属性值
  .st 力量35…          # 没有人物卡时自动以当前 QQ 昵称建默认卡
  ```

* 理智检定：
  ```
  .sc 1d6/1d10       # SAN Check（成功损失1d6/失败损失1d10）
  .ti                # 临时疯狂
  .li                # 长期疯狂
  ```

* 先攻系统：
  ```
  .ri                # 掷先攻
  .ri +3             # 掷先攻（+3调整值）
  .init              # 查看先攻列表
  .ed                # 结束当前回合
  ```

* 插件开关（按群独立，群内所有人可用）：
  ```
  .bot               # 查看骰娘简介（可在配置中自定义）
  .bot off           # 关闭本群骰娘功能（掷骰/人物卡/日志/先攻）
  .bot on            # 重新开启本群
  .dismiss           # 立即让骰娘退出本群
  ```

* 日志管理：
  ```
  .log new <日志名>   # 开始新日志
  .log off            # 暂停日志并生成本段小结 + 高光
  .log on             # 恢复日志
  .log end            # 结束并导出日志
  .log list           # 列出所有日志
  .log del <日志名>   # 删除日志
  .log get <日志名>   # 下载日志文件
  .log stat <日志名>  # 查看日志统计
  .log draw           # 把最近一段的第 1 条高光画成插图
  .log draw 2         # 画第 2 条高光
  .log draw all       # 画前几条（数量受 max_per_call 限制）
  .log draw cover     # 用整段小结画章节封面
  ```

如需完整指令说明，请运行 `.dicehelp` 查看。

## 配置

所有输出文本和参数均可在 Astrbot 的插件配置界面中修改，无需编辑代码。

配置分类：

- **bot** - 骰娘开关的默认状态、`.bot` 自定义介绍
- **log_summary** - `.log off` 阶段总结：独立 Provider/模型、超时、字符上限、高光条数
- **log_illustration** - `.log draw` 高光配图：绘图插件名、**画风基准（需手动修改）**、宽高比、超时、冷却、权限与额度策略
- **output** - 所有输出文本模板（支持 `{变量名}` 占位符）
- **dice** - 掷骰参数（默认面数、最大个数/面数等）
- **initiative** - 先攻掷骰范围
- **sanity** - 理智检定和疯狂症状配置
- **character** - COC/DND 角色生成骰子公式
- **coc_rules** - 大成功/大失败规则
- **growth** - 技能成长阈值

### 高光配图与万象画卷联动

1. 安装并启用 [万象画卷](https://github.com/diaomin66/astrbot_plugin_omnidraw)，在它的配置里填好至少一个「画图」节点（接口地址、模型、API Key）。
2. 打开 AstrBot 后台 → 插件管理 → 骰娘 → **联动检查** 页面，点「开始检查」确认状态为就绪。
3. 在骰娘配置的「高光时刻配图」中**手动填写画风基准**（`style_prompt`），例如「日系动画关键帧插画，干净线稿，赛璐璐上色」。
4. 建议把万象画卷的副脑风格也改成插画风（如「日系插画大师」或「自定义模式」），否则副脑可能把提示词改写成日常摄影风。
5. 跑团时先 `.log off` 生成小结与高光，再在群里用 `.log draw` 画出高光插图。
